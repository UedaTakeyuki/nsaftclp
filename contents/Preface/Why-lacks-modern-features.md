# Why the C standard library lacks modern features.

The C language predates modern computing, such as the Desktop, HTTP, JSON and so on. The first edition of the original C language primer, which is known as ["K&R"](https://en.wikipedia.org/wiki/The_C_Programming_Language), was published in the year 1978, there was neither a Desktop nor the HTTP protocol back then.
Even the year 1988 when the 2nd edition was published, this was a year before I graduated from university with a degree in high-energy theoretical physics and started my career as a software engineer, I remember well that desktop computing was a luxury item available only on expensive UNIX workstations.
