# Preface

## Congratulation, but…
Congratulations on the completion of the **C Language primer**. I know now you can make any useful programs to handle **files** and **command line**. 
I see your grumbling "**That's all?**　Just **files** and **console IO**?, Can I make a cool **Desktop** application passing and accepting **JSON** data via **HTTP** protocol in C?". 
For now, the answer is **NO**. 
Since you have completed the introduction to the C language, you must be familiar with handling the **C standard library**, but unfortunately, there is no such **modern kind of stuff** there. 

## Libraries that realize modern features that are not available in the standard library of the C language
Unlike modern languages ​​such as Python and Go, the C language has a long history spanning more than half a century.
Throughout its history, the C standard library has been conservative in incorporating modern features.
Instead, most of the modern features are implemented and maintained by a diverse and active community of C users.


So, to create applications using modern features in C, you need to be familiar with them as well.
